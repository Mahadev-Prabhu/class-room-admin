Super Admin User Guide
Early Learning Library Admin Portal

Production URL: https://class-room-admin.vercel.app/login

Purpose

This guide explains the Super Admin features used to manage schools, class codes, teachers, students, and system-level records.

Access and Passwords

  • Super Admin users sign in with email and password.
  • To create a Super Admin account, open the sign-in page and tap the app logo five times. The hidden sign-up option will appear.
  • Google and Apple sign-in are not supported in this portal.
  • Use Reset Password on the sign-in page if a password needs to be changed.
  • Super Admin can send password reset links for school accounts and teacher accounts when needed.

Dashboard

The Dashboard shows overall system counts across all schools, teachers, students, class codes, books read, and activity.

Schools

The Schools section is available only to Super Admin.

ActionWhat It Does
Create School AccountCreates a school admin login. The school completes school details during first-time setup.
Use Enrolled Teacher AccountAdds school admin access to an enrolled teacher account, only if the teacher is not already connected to another school.
InfoShows school name, email, location, phone, teacher count, student count, and account details.
View TeachersOpens the Teachers page filtered to that school.
View StudentsOpens the Students page filtered to that school.
Send Reset Password LinkSends a secure password reset email to the school admin.
Activate / DeactivateControls whether the school admin can access the portal.

Class Codes

Class Codes are used to connect teacher accounts with class access and student limits.

StatusMeaning
AvailableThe class code exists and is not used by any teacher.
Teacher ClaimedA teacher has used the class code, but the teacher is not yet connected to a school.
School AssignedA teacher has used the class code and the teacher is connected to a school.
ExpiredThe class code expiry date has passed.
  • Create class codes with expiry date and student limit.
  • Search class codes by code, teacher, or school.
  • Filter class codes by type.
  • Sort class codes by status and assigned school.
  • Delete expired, teacher claimed, or unused class codes after confirmation.

Deleting an expired or teacher claimed class code may also remove the teacher account and related student links from the database. Codes assigned to a school are not part of normal cleanup unless they are expired and confirmed for removal.

Teachers

The Teachers section shows all teacher accounts in the system.

ActionWhat It Does
InfoShows email, class code, school, last sign-in, student count, class assignments, and individual assignments.
Set SchoolConnects a teacher with a claimed class code to the correct school and updates the displayed school name.
Create Incoming TeacherCreates a teacher account without a class code. This teacher appears as Class Code Pending until a class is transferred.
Transfer ClassMoves the class code and linked students from an enrolled teacher to an incoming teacher.
Delete TeacherDeletes a teacher only when the teacher has no active class code and no students.
Send Reset Password LinkSends a secure reset link after the teacher has an active class code.
Share DetailsShares teacher email, class code, and sign-in instructions after the teacher has an active class code.

Incoming Teacher Flow

  1. Create an incoming teacher account with teacher name, teacher email, and password.
  2. Optionally select a school while creating the incoming teacher.
  3. The teacher appears as Class Code Pending.
  4. Use Transfer Class from the enrolled teacher.
  5. Select the incoming teacher.
  6. The class code and linked students move to the incoming teacher.
  7. The enrolled teacher is changed to Class Code Pending and remains visible so the school can decide what to do next.
  8. The enrolled teacher keeps teacher_code with an empty value.
  9. The enrolled teacher keeps assigned class/books data.
  10. After transfer, send a reset password link or share teacher details with the incoming teacher.

Students

Super Admin can view all students in the system, with filters for school and teacher context.

  • Use Info to view parent email, last used, age, class code, teacher name, books read, and Smart Coins.
  • Delete one selected child profile from a student account that has more than one child.
  • Delete the entire student account, including all child profiles under it, when needed after confirmation.
  • Student movement validates teacher eligibility, class code expiry, and student limit.

Important Rules

  • A school cannot add a class code that is already assigned to another school.
  • A Class Code Pending teacher must not already have an active class code or students before receiving a transferred class.
  • Teacher login details should be shared only after the teacher has an active class code.
  • Firebase Auth account deletion depends on backend function support.

Testing Checklist

  • Super Admin sign-in and dashboard loads.
  • Create school account and send reset password link.
  • Create class code with valid format.
  • Reject class code with invalid format.
  • Set school for a teacher with claimed class code.
  • Create incoming teacher and transfer class.
  • Confirm enrolled teacher keeps assigned class/books data.
  • Confirm teacher details can be shared only after transfer.
  • Delete single child profile from a multi-child student account.
  • Delete entire student account after confirmation.
  • Delete allowed expired class code after confirmation.
