School Admin User Guide
Early Learning Library Admin Portal

Production URL: https://class-room-admin.vercel.app/login

Purpose

This guide explains the School Admin features used to manage teachers and students connected to one school.

Access and First-Time Setup

  • School Admin users sign in with email and password.
  • Google and Apple sign-in are not supported in this portal.
  • During first-time setup, the school enters school name, country, state, address, zip code, and phone number.
  • Use Reset Password on the sign-in page if a password needs to be changed.

Dashboard

The Dashboard shows counts only for teachers and students connected to the School Admin's school.

Teachers

The Teachers section shows teachers connected to the school. Teachers with Class Code Pending status remain visible so the school can decide whether to keep or delete them.

Add Enrolled Teacher

Use this when a teacher has already signed up in the mobile app with a class code, but is not yet linked to this school.

  1. Open Teachers.
  2. Select Add Teacher.
  3. Select Enrolled Teacher.
  4. Enter the class code provided by the teacher.
  5. Select Validate Class Code.
  6. The portal checks that the code exists, is already claimed by a teacher, is not expired, and is not assigned to another school.
  7. After successful validation, the expiry date and student limit are shown and cannot be edited.
  8. Select Add Teacher to connect the teacher to the school.

Create New Teacher Account

  1. Open Teachers.
  2. Select Add Teacher.
  3. Select New Account.
  4. Enter an unused valid class code, teacher email, and password.
  5. The portal validates the class code before creating the teacher account.
  6. The teacher account is created and connected to the school.

The school should share teacher login details carefully. A reset password link is preferred when possible.

Students

The Students section shows only students connected to teachers in the school.

  • Use Info to view parent email, last used, age, class code, teacher name, books read, and Smart Coins.
  • If one student account has multiple child profiles, each child can appear separately in the child name area.
  • Move Student is available when another eligible teacher exists and validation passes.
  • Delete one selected child profile from a student account that has more than one child.
  • Delete the entire student account, including all child profiles under it, when needed after confirmation.

Deleting student data can remove books read, rewards, Smart Coins, and child history. Confirm carefully before deleting.

Settings

  • View and update school information.
  • Sign out from the portal.
  • A confirmation message is shown before signing out.

Important Rules

  • A school can add an enrolled teacher only when the class code is claimed by that teacher and not assigned to another school.
  • A school cannot edit class code expiry date or student limit.
  • A teacher cannot be deleted if the teacher has an active class code or students.
  • Class Code Pending means the teacher currently has no active class code.

Testing Checklist

  • School Admin sign-in works.
  • First-time school setup works.
  • Add enrolled teacher by class code.
  • Reject class code already assigned to another school.
  • Create new teacher account with unused class code.
  • Teacher info dialog shows expected details.
  • Share teacher details only after teacher has active class code.
  • Students page shows only students connected to the school.
  • Delete selected child profile from a multi-child student account.
  • Delete entire student account after confirmation.
  • Update school information in Settings.

Glossary

TermMeaning
Super AdminAn internal admin user who can manage schools, class codes, teachers, students, and system-level records.
School AdminA school or center admin user who can manage only the teachers and students connected to their school.
Class CodeA code used to connect a teacher account with class access and student limit.
AvailableA class code exists and is not used by any teacher.
Teacher ClaimedA teacher has used the class code, but the teacher is not yet connected to a school.
School AssignedA teacher has used the class code and the teacher is connected to a school.
ExpiredThe class code expiry date has passed.
Enrolled TeacherA teacher who already exists in the system and has claimed a class code, but may not be linked to a school yet.
Class Code PendingA teacher has no active class code yet.
Reset Password LinkA secure email that lets the user set or reset their password.
Student AccountThe login account used by a family/student. One student account can contain one or more child profiles.
Child ProfileAn individual child record inside a student account. It stores that child's name, age, reading activity, rewards, and teacher/class connection.
